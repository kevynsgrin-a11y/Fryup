# Fryup.UK — Measurement & Units Standard

## Core Principle
Fryup.UK is a **Metric-First UK publication**. All primary quantities are written using standard metric SI units and UK kitchen conventions.

---

## 1. Unit Conventions

| Measurement Type | Primary Unit (Canonical) | Formatting Rule | Example |
|---|---|---|---|
| Mass / Weight | grams (`g`), kilograms (`kg`) | Whole numbers for grams, 1 decimal for kg | `150g back bacon`, `1.2kg potatoes` |
| Liquid Volume | millilitres (`ml`), litres (`l`) | Whole numbers for ml | `300ml whole milk`, `1.5l water` |
| Temperature | Celsius (`°C`), Fan (`°C fan`) | State fan-assisted oven temp first, gas mark second | `200°C (180°C fan / Gas Mark 6)` |
| Length / Thickness | millimetres (`mm`), centimetres (`cm`) | Whole numbers | `1.5cm slice black pudding` |
| Count / Units | item count | Descriptive count with prep note | `4 rashers unsmoked back bacon` |

---

## 2. Terminology Glossary

- **Bacon**: "Back bacon" (eye of loin + tail of belly). Specify "smoked" or "unsmoked". Avoid calling bacon "strips" (use "rashers").
- **Sausages**: "Cumberland" (coarse pork, black pepper), "Lincolnshire" (sage forward), "Chipolata" (thin breakfast link).
- **Bread**: "Farmhouse white", "bloomer", "sourdough", "crumpet", "English muffin".
- **Sandwich Rolls**: "Bap", "cob", "roll", "bun". Primary canonical label: "Bap".
- **Sauces**: "Brown sauce" (tart fruit/vinegar/spiced malt sauce), "Tomato ketchup".
- **Pans**: "Frying pan", "cast-iron skillet", "baking tray", "griddle".
